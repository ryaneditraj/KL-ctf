# Open this folder in Cursor — that’s the whole product

**Repo:** KL-ctf (CypherFlag)  
**You:** Aaliya (or any non-technical operator)  
**You do not code. You do not use Terminal.**

## 60-second start

1. Clone / download this repo  
2. In Cursor: **File → Open Folder** → this folder  
3. Open **Agent** chat  
4. Type anything (`hi` is enough) — the AI must read `START_HERE.md` and set itself up  
5. Open the competition website  
6. Paste each challenge into the chat → click **Allow** when asked → copy lines that start with `FLAG:` → submit on the website  

Optional stronger first message (copy-paste):

```
I am Aaliya. Boot KL-ctf. Teach me the 2-minute version from AALIYA.md, then wait for challenges.
```
